# Frank Yomik v2.0.6

This patch is the third routine weekly dependency batch.

- Update `transformers` to 5.24.1 (newer than Dependabot's 5.23.0 target),
  `opencv-python-headless` to 5.1.0.95, and `numpy` to 2.5.5.
- Regenerated the universal worker dependency lock and pipeline revision
  (`sha256:237cf3a4…` → `sha256:23797c3b…`). Every page cached under an older
  revision is now a miss and will regenerate lazily on first request.
- Pass `--no-fatal-infos` to `flutter analyze` in CI so Flutter 3.47+
  `package:flutter/material.dart` deprecation info notices do not fail the
  analyzer job while warnings and errors remain fatal.

The application behavior, model choices, cache schemas, and v2 compatibility
contract are unchanged. Deploy the API and worker as a matched v2.0.6 pair so
their pipeline revisions agree.

See [v2.0.5 release notes](v2.0.5.md) for the previous routine batch and
[v2.0.3 release notes](v2.0.3.md) for the Pillow security release.
