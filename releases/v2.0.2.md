# Frank Yomik v2.0.2

This patch fixes touch-and-hold magnification on Android.

- Releasing the magnifier no longer also flips the Kindle page.
- Short taps continue to turn pages normally.
- Scroll gestures that move before the hold threshold remain untouched.
- The Flutter and Chromium lens implementations now share the same touch
  release handling.

The server pipeline and v2 compatibility contract are unchanged from v2.0.1.
