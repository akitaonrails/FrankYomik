# Frank Yomik v2.1.0

This minor release adds optional per-series furigana reading overrides and
translation term glossaries, and decouples `kindle.furigana` / `kindle.processor`
imports from `fugashi` at module import time.

- **Per-series reading overrides and term glossaries (#8):**
  - Added an optional `glossaries:` section to `server/config.yaml` keyed by
    series title (case-insensitive) or slug, supporting `reading_overrides`
    (for `manga_furigana` and `book_furigana`, including multi-morpheme
    character names) and `terms` (injected into `PageTranslationRequest` and
    single-item fallbacks for `manga_translate` and `webtoon`).
  - Updating `server/config.yaml` and refreshing `stage_manifest.json` derives
    a new `PIPELINE_REVISION`, cleanly invalidating cached pages.
- **Lazy `fugashi` import (#7):**
  - Deferred `import fugashi` inside `kindle.furigana._get_tagger()` so
    importing `kindle.furigana` or `kindle.processor` for pure-Python helpers
    or `PipelineMode.TRANSLATE` does not require MeCab/UniDic at import time.
- **Pipeline revision:** `sha256:23797c3b…` → `sha256:c0634adb…`.

Deploy the API and worker as a matched v2.1.0 pair so their pipeline revisions
agree.
