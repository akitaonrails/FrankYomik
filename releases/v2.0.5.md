# Frank Yomik v2.0.5

This patch is the second routine weekly dependency batch.

- Update `transformers` to 5.22.2 and `huggingface-hub` to 2.4.0 (model
  download and inference client runtimes; symbol surface and a live model
  download verified unchanged).
- Update `nodriver` (Webtoon scraping driver) to 0.50.99 and `pytest` to
  9.2.0.
- Regenerated the universal worker dependency lock and pipeline revision
  (`sha256:ecbac1c2…` → `sha256:237cf3a4…`). Every page cached under an older
  revision is now a miss and will regenerate lazily on first request.

The application behavior, model choices, cache schemas, and v2 compatibility
contract are unchanged. Deploy the API and worker as a matched v2.0.5 pair so
their pipeline revisions agree.

[v2.0.3 release notes](v2.0.3.md) for the Pillow security release.
