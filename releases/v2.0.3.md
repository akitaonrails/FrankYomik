# Frank Yomik v2.0.3

This security patch closes all 43 open Dependabot advisories on the server
runtime, most of them in Pillow — several are remote-code-execution bugs in
image decoders, which is exactly the code path the worker uses for every
upload.

- Update `Pillow` from 12.3.0 to 13.0.0: fixes the FlashPix (FPX) heap
  overflow RCE (CVE-2026-112398), Ghostscript argument injection RCE
  (CVE-2026-112900), multi-frame loader stale-storage corruption
  (CVE-2026-96639, CVSS 9.8), JPEG decode overflow, BMP RLE DoS, tiled-TIFF
  overread, and the bundled libopenjp2 heap overflow.
- Weekly Dependabot version updates are now enabled for `server/`, and
  `simple-lama-inpainting >= 0.1.1` is ignored: it declares `pillow<10` and
  can never lock against the mandated Pillow 13 pin.
- Routine dependency refresh: `transformers` 5.20.2, `huggingface-hub` 2.2.0,
  `opencv-python-headless` 5.0.0.93, `numpy` 2.5.4, `redis` 8.1.0,
  `nodriver` 0.50.6.
- Regenerated the universal worker dependency lock and pipeline revision
  (`sha256:4c2b6905…` → `sha256:a0b31bba…`). Every page cached under an older
  revision is now a miss and will regenerate lazily on first request.

The application behavior, model choices, cache schemas, and v2 compatibility
contract are otherwise unchanged. Deploy the API and worker as a matched
v2.0.3 pair so their pipeline revisions agree.

See [v2.0.2 release notes](v2.0.2.md) for the client-side fixes and
[v2.0.0 release notes](v2.0.0.md) for the major pipeline changes.
