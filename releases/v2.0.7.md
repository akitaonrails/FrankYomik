# Frank Yomik v2.0.7

This patch completes the third routine weekly dependency batch (superseding the
unpublished `v2.0.6` tag, whose Android APK build failed after GitHub Actions
moved floating `stable` Flutter to 3.50.1).

- Pin Flutter to `3.47.9` in CI and Release workflows so the Android Gradle
  8.14 / AGP 8.11.1 / Kotlin 2.2.20 toolchain builds reproducibly across all
  platforms until the Android project is upgraded to Gradle 9 / AGP 9.
- Includes all `v2.0.6` dependency updates: `transformers` 5.24.1,
  `opencv-python-headless` 5.1.0.95, `numpy` 2.5.5, universal worker lock, and
  pipeline revision `sha256:23797c3b…`.

The application behavior, model choices, cache schemas, and v2 compatibility
contract are unchanged. Deploy the API and worker as a matched v2.0.7 pair so
their pipeline revisions agree.

See [v2.0.5 release notes](v2.0.5.md) for the previous published routine batch.
