# Frank Yomik v2.0.1

This security patch updates the Python HTTP and test runtimes after GitHub
indexed two new medium-severity advisories immediately after v2.0.0 was
published.

- Update `requests` from 2.32.5 to 2.34.2 for nondeterministic temporary
  extraction paths.
- Update `pytest` from 9.0.2 to 9.1.1 for secure temporary-directory handling.
- Regenerate the universal worker dependency lock and pipeline revision.

The application behavior, model choices, cache schemas, and v2 compatibility
contract are unchanged. Deploy the API and worker as a matched v2.0.1 pair so
their pipeline revisions agree.

See [v2.0.0 release notes](v2.0.0.md) for the major pipeline changes and
[the v2 security audit](../docs/security_audit_v2.md) for the complete review.
