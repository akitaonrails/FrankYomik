# Frank Yomik v2.0.4

This patch updates the Hugging Face client library on the server.

- Update `huggingface-hub` from 2.2.0 to 2.3.0 (current PyPI latest; no
  transitive dependency drift).
- Regenerated the universal worker dependency lock and pipeline revision
  (`sha256:a0b31bba…` → `sha256:ecbac1c2…`). Every page cached under an older
  revision is now a miss and will regenerate lazily on first request.

The application behavior, model choices, cache schemas, and v2 compatibility
contract are unchanged. This release also enables the weekly Dependabot
pipeline added after v2.0.3: this is its first routine batch. Deploy the API
and worker as a matched v2.0.4 pair so their pipeline revisions agree.

See [v2.0.3 release notes](v2.0.3.md) for the Pillow security release.
